# Scope is Go security only

Superseded by ADR 0012.

This repo holds only Go security skills that can be shipped to others. It is not a general personal skills collection, which is why it is named `go-security-skills` and not `skills` (the convention for general collections). A talk call to action must point at one clear thing, and a topic-scoped repo is easier to find and to explain in one line. Skills that are generic but useful, such as ADRs, are out of scope: Matt Pocock's skills already cover them.
